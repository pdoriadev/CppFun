Toggle showing spaces and tabs
- set list 
- set nolist

Toggle showing line numbers
- set number
- set nonnumber

Cut/Paste
- v for visual mode.
- highlight, then press d to cut
- press p to paste

YANK!!! (Copy)
- yy - copy line, including newline characer
- 3yy - copy 3 lines starting from the current lne
- y$ - copy from the cursor to the end of the line
- y^ - copy from the cursor to the start of the line
- yw - copy from the cursor to the start of the next word
- yiw - copy the current word (without surrounding spaces)
- yaw - copy the current word (with surrounding spaces)
- yi( - copy the text inside parentheses
- yi{ - copy the text inside curly braces
- y% - copy to the matching bracket. Works with (), {}, and []

Search for Pattern
- /word - all occurrences of "word"
- /\<word\> - patterns that are just "word"

Replace string
- %s/stringToReplace/replacementString - replaces all instances of the string
- 0, 6s/stringToReplace/replacementString - replaces all instances of stringToReplace with replacementString between lines 0 and 6 (inclusive). 

Tabs
- set tabstop=2 - sets tab size to two spaces
- set shiftwidth=2 - NOT SURE WHAT THIS IS. NEED TO LOOK IT UP.
- set expandtab - converts tabs to spaces
- original reference: https://stackoverflow.com/questions/2054627/how-do-i-change-tab-size-in-vim

Moving the cursor
- 0 - beginning of line
- $ - end of line
- e - end of next word
- w - beginning of next word
- b - beginning of previous word

Control Flow Keys (terminal, not neovim?)
- Ctrl-S - Pause  Display
- Ctrl-Q - Restart Display
- Ctrl-C - Cancel Operation
- Ctrl-U - Cancel Line
